# kmsim (Asterios Panoras, Apache-2.0)

An exact NumPy simulator for the subset of the kickmix text format (`.kmx`, `.kmx.gz`) used in this competition. It
needs no kickmix, so it works as an independent fallback check. It is not the official verifier.

Copied unmodified from Asterios Panoras's public QCC Atlas toolkit
(<https://www.kaggle.com/code/asteriospanoras/qcc-atlas-toolkit-in-notebook-chemistry-refit>); see the file's own
docstring for semantics and usage, e.g. `python kmsim.py circuit.kmx --xmax 3133452` for every invsqrt input.
